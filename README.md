# 廠內藥液槽車回報（Factory Chemical Tanker Report）

專為工廠化學藥液槽車入料／卸料現場打造的 Android 安全檢核拍照與回報 App（v2.2）。

## ✨ 主要功能
- **藥水雙重確認防呆機制**：
  - 全新車次／清空後預設「尚未確認藥液」（琥珀黃醒目警示），避免誤用預設藥液名稱。
  - 拍照或備份前未選藥液會自動彈出選擇視窗，選完立即接續作業。
  - 寄出回報前再次彈出最終核對視窗（藥液名稱、照片張數、收件信箱），並可一鍵更改藥液。
- **6 宮格現場安全檢核拍照卡片**：
  - 依序檢核：`貨車車牌`、`車輪檔`、`[藥液] 藥液出口`、`[藥液] 藥桶入口`、`貨車接地線`、`司機防護裝備`。
  - 支援 **即時正立照片縮圖預覽**（含 `ExifInterface` 自動轉正）、完成進度條（`X / 6`）、大圖預覽重拍／刪除。
- **多藥液一鍵切換**：
  - 內建 `氯化銅`、`液鹼`、`氯化鐵`、`氯化亞鐵`、`硫酸`、`酸化助劑` 及 `+ 自訂` 橫向膠囊選單。
- **歷史備份圖庫與批次補寄**：
  - 依日期分組折疊瀏覽，支援「全選當日」、多選勾選補寄 Email 與自動清理過期照片（3 / 7 / 14 / 30 天）。
- **穩定性與效能優化**：
  - 全非同步背景執行緒（`ExecutorService`）處理影像縮放與備份，不卡頓。
  - 採用 `ActivityResultLauncher` 與狀態持久化，避免拍照時背景回收遺失資料。

## 🛠️ 技術棧與建置環境
- **語言**：Java 17
- **建置工具**：Gradle 9.6.0 / Android Gradle Plugin 9.4.1
- **SDK**：`compileSdk 34` / `targetSdk 34` / `minSdk 24`
- **套件**：AndroidX AppCompat、Material Components、ExifInterface

## 🚀 本地建置
```bash
./gradlew assembleDebug
```
產出 APK 位於 `app/build/outputs/apk/debug/app-debug.apk`。
